Prerequisites

This section outlines the list of software installation necessary to run the Campus Enablement – Business Process Management program.

It is recommended that participants are able to complete the steps as outlined below prior to the commencement of the program.

It may take roughly about 1.5 or 2 hours to complete these steps.

General

  • Require access to internet to download development tools in support of this program. The general tools are as listed in this section.
  • Each participant to have access to a desktop / laptop / VM matching below configuration or better.
    • Windows OS or Mac OS
    • 8 GB RAM
    • 50+ GB Disk space
    • Supported Browser
      • Google Chrome latest [recommended]
      • Mozilla Firefox latest
      • Microsoft Edge latest
  • Participants need to have admin rights on their respective device to install / edit some configurations. It is also necessary to help in debugging runtime errors.

Java JDK

Install Java JDK 21. Open JDK download link is provided below.

https://www.openlogic.com/openjdk-downloads

Run below command to make sure you have the right version installed.

$ java -version
openjdk version "21.0.5" 2024-10-15
OpenJDK Runtime Environment OpenLogic-OpenJDK (build 21.0.5+11-adhoc.admin.jdk21u)
OpenJDK 64-Bit Server VM OpenLogic-OpenJDK (build 21.0.5+11-adhoc.admin.jdk21u, mixed mode, sharing)

*Note: Your specific output may vary slightly depending on the OS (Windows / Linux / MacOS)

Atom Text Editor

Require a text editing tool (log file or config file mostly) such as Atom.

Download from here.

https://github.com/atom/atom/releases/tag/v1.60.0

GIT: Bash and CLI

Install the command line interface using below URL.

https://cli.github.com

Install the Git Bash for Windows utility. Refer to the video for instructions.

IntelliJ IDEA

Install development tool (Integrated Development Environment – IDE) so that we can run Microservices / APIs locally.

Please feel free to use the IntelliJ Community Edition (Free) or Eclipse IDE if you wish. For University students though, you have an option to download IntelliJ IDE student edition.

Step 1. First, you will need to create a user account.

https://www.jetbrains.com/community/education/#students/

Use below navigation to register as University Student or Teaching Faculty for free license. Navigate or scroll down and click on Apply now.

Complete the steps using your Email id (University / College).

You will receive a link to activate your account.

After successful completion, you will see license id on your account page.

Step 2. Download the software and launch the IntelliJ IDEA app.

You will be prompted to add license key.

After adding license key, you are now ready to work with IDE.

Docker

This is optional for the initial sessions. Docker is required while discussing Connector concepts in detail, during second half of the workshop.

Install Docker desktop edition to run Camunda components locally.

Download via this URL: https://www.docker.com

Create an account if you do not already have one.

Complete the steps as prompted. You should see a screen similar to this, with Docker Desktop.

Camunda 8 Desktop Modeler

Install the Modeler UI app by following the steps.

  • Open the above URL in a new tab.
  • Go to section “Open Source Desktop Modeler” -> “Desktop“
  • Select an option based on your Operating System.
  • Follow the instructions as listed under “Get Started“.

Make sure you are able to open the Camunda Modeler UI app by launching the application.

Token Simulator Plugin

This is by far the most commonly used Camunda Modeler UI plugin. It helps the process analyst (author and/or stakeholders) to analyse how the process definition potentially runs post deployment.

https://github.com/camunda/camunda-modeler-token-simulation-plugin
